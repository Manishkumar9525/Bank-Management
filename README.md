# 🏦 Bank Management System

A simple and interactive **Bank Management System built with Python** that simulates basic banking operations through a command-line interface.

The project is designed to practice and demonstrate important **Python Object-Oriented Programming (OOP)** concepts along with file-based data storage using JSON.

## ✨ Features

* 👤 Create a new bank account
* 💰 Deposit money
* 💸 Withdraw money
* 📋 View account details
* ✏️ Update account information
* 🗑️ Delete a bank account
* 🔐 PIN-based account verification
* 💾 Store and retrieve account data using JSON
* ⚠️ Handle invalid inputs and runtime errors

## 🛠️ Technologies Used

* **Python** — Core programming language
* **Object-Oriented Programming (OOP)** — Classes, objects, encapsulation, inheritance, abstraction, and polymorphism
* **JSON** — Used for storing account information
* **Pathlib** — Used for file and path handling
* **Random & String** — Used for generating unique account numbers
* **Exception Handling** — Used to handle runtime errors safely
